# 블루타이거 100 번호 뽑기

여러 명이 동시에 접속해도 같은 번호판을 보는 뽑기 페이지예요. 누가 번호를 뽑으면 다른 사람 화면에도 3초 안에 뽑힌 상태로 바뀌어요.

- 페이지: `index.html` (GitHub Pages)
- 데이터: `Code.gs` (Google Apps Script + 스프레드시트)
  - 번호판 상태(경품 위치, 공개된 번호)는 스크립트 속성에 저장돼요. 아직 안 열린 번호의 경품 위치는 참가자에게 보내지 않아요.
  - 뽑을 때마다 시트의 `기록` 탭에 회차, 시각, 번호, 등급, 상품이 한 줄씩 쌓여요.
- 링크는 하나예요. 진행자 여러 명이 같은 링크로 동시에 접속해 뽑기, 리셋, 경품 설정, 당첨 번호 보기를 모두 할 수 있어요.

## Apps Script 연결
1. 구글 시트를 새로 만들고 `확장 프로그램 > Apps Script`를 열어요.
2. `Code.gs` 내용을 붙여 넣고 저장해요.
3. `배포 > 새 배포 > 웹 앱`, 실행 계정 `나`, 액세스 권한 `모든 사용자`로 배포해요.
4. 나온 웹 앱 URL(`.../exec`)을 `index.html`의 `const API = '...'`에 넣어요.
5. 코드를 고친 뒤에는 `배포 > 배포 관리 > ✏️ > 버전: 새 버전 > 배포`로 올려야 URL이 그대로 유지돼요.
